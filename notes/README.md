# Конспекты

Этот каталог можно открыть в Obsidian как отдельный vault. Локальные настройки
Obsidian (`.obsidian/`, `.trash/` и plugin metadata) исключены из Git.

Основной маршрут обучения находится в
[плане Senior AI Agent Engineer 2026](../docs/senior_ai_agent_engineer_2026.md).

Для каждого пройденного модуля создаётся отдельный каталог:

```text
notes/module_XX_topic/
├── module_XX_topic.md
└── module_XX_topic.pdf
```

Markdown является редактируемым source of truth, PDF — производным артефактом.
Оба формата создаются и проверяются через
[`build-lesson-notes`](../skills/build-lesson-notes/SKILL.md).
