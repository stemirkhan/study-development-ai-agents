# Визуальная система учебных презентаций

## Характер

Использовать спокойный инженерный интерфейс: ясный, тёплый, точный. Слайды должны
напоминать хорошо отредактированный технический документ, а не marketing landing
page или cyberpunk dashboard.

## Токены

Сохранять базовые токены шаблона:

```css
--canvas: #eef2f4;
--surface: #ffffff;
--surface-subtle: #f6f8f9;
--ink: #17212b;
--muted: #5d6975;
--line: #d9e0e4;
--accent: #315c6d;
--accent-soft: #e7f0f2;
--success: #306449;
--warning: #755a24;
--danger: #8a4545;
```

Допускать один дополнительный цвет только для смысловой категории. Не кодировать
состояние одним цветом.

## Типографика

- Использовать системный sans-serif для текста и monospace только для кода,
  state и идентификаторов.
- Держать body text не меньше `clamp(1rem, 1.5vw, 1.35rem)`.
- Ограничивать строку примерно 55–75 символами.
- Использовать максимум три уровня визуальной иерархии на слайде.
- Не уменьшать шрифт, чтобы вместить лишний текст; разделить слайд.

## Layout

- Использовать 8px spacing scale и внутренние поля через `clamp()`.
- Ограничивать content width примерно 1180–1280px.
- Использовать одну или две колонки; три — только для короткого сравнения.
- Оставлять заметное свободное пространство.
- Размещать основное действие в одном предсказуемом месте.

## Motion

- Использовать переходы 160–220ms только после явного действия.
- Не запускать непрерывное движение, мигание или autoplay.
- Не анимировать одновременно больше одного смыслового слоя.
- Полностью уважать `prefers-reduced-motion`.

## Accessibility

- Поддерживать WCAG AA contrast.
- Сохранять видимый `:focus-visible`.
- Использовать нативные `button`, `a`, `details` и семантические заголовки.
- Давать `alt` изображениям и текстовый эквивалент диаграммам.
- Не помещать важный контент только в hover state.

## Запрещённые приёмы

- neon/glow и кислотные акценты;
- glassmorphism и полупрозрачные панели поверх пёстрого фона;
- большие декоративные градиенты;
- фоновые particles, parallax и бесконечно движущиеся линии;
- fake terminal как универсальный контейнер;
- чрезмерные тени, скругления и badges;
- emoji вместо устойчивой визуальной системы;
- скрытая навигация или жесты без экранных кнопок.
